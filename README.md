# Before You Let AI Write Your Code, Ask the Right Question

**Essay: The Real Leverage Problem: AI in Software Development**

By Mohammed Khalid Shaik

## Abstract

The hardest problem in applying AI to software development isn't capability, it's classification: deciding which problems are probabilistic and which are deterministic, and then which of the probabilistic ones are worth the cost of AI involvement. The essay argues that AI is a risk where deterministic precision is required (architecture, production systems) and a multiplier where probabilistic output is good enough (error handling, logging, testing, boilerplate, documentation), and that the right role for AI shifts across the project lifecycle from prototype to production and migration.
